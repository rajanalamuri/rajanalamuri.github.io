Free visual lessons on algorithms and data structures for children aged 8 to 14. Watch, predict, then finish offline with cards or paper. No accounts, ads, tracking, streaks or autoplay, and a daily time limit across the site.

Polygon Annotator

A lightweight, offline annotation tool for computer-vision datasets: N-sided polygons with draggable vertices, a pixel magnifier, keyboard shortcuts and JSON export. Runs standalone in the browser or with Docker.

GitHub
Python library · Apache 2.0

dataset-fingerprint

A lockfile for training data. Versions any dataset (images, audio, video frames, sensors, text, tables) on local disk, S3, Azure, GCS or Databricks, with integrity and split checks on every commit.

pip install dataset-fingerprint

Reference implementation

Dataset manifest versioning

The idea dataset-fingerprint grew from: version a small manifest describing the data instead of the data itself. One JSON file per version on S3, recorded in Git and created by CI, so every model can name exactly what it was trained on.
